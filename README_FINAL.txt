HMI KOMISARIAT UNPI — CMS FINAL

Cara menjalankan:
1. npm install
2. npm start
3. buka http://localhost:3000

Admin:
- buka admin.html
- login dengan ADMIN_USER/ADMIN_PASSWORD dari environment, atau default development yang ada di server.js

Fitur CMS:
- Berita, agenda, galeri
- Struktur organisasi lengkap: nama, jabatan, bagian, periode, urutan, tampil/sembunyikan, foto
- Profil, kontak, background, footer
- Konten halaman dasar
- Media Manager
- Database kader & penerimaan kader tetap terpisah dari data publik
